# Contribuir

1. Describe el problema y cómo reproducirlo.
2. Separa resultados de PC y pruebas en reloj real.
3. Para correcciones táctiles, añade una prueba que falle antes y pase después.
4. No afirmes porcentajes de mejora sin mediciones.
5. No incluyas firmware propietario, archivos personales, claves o direcciones MAC.
6. Revisa las advertencias de licencia antes de proponer código derivado.

Las contribuciones no deben asumir que Project Beyond está afiliado a Samsung.
