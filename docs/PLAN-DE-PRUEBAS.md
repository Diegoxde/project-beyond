# Plan de pruebas — v24

Las pruebas de host no sustituyen las pruebas en la Galaxy Fit3 real. Registrar firmware, condiciones y resultado de cada ensayo.

## Antes de probar

- [ ] Confirmar que el reloj está en stock AZA3 y arranca.
- [ ] Revisar batería (≥50 %) y desconectar otros enlaces Bluetooth.
- [ ] Seguir el procedimiento de seguridad y recuperación.
- [ ] No instalar v24 directamente sobre v12.

## Pruebas en el reloj

- [ ] Launcher: tocar cada fila sin deslizar.
- [ ] Galería: abrir una foto, cerrar y repetir varios toques.
- [ ] Teclado: pulsar teclas en diferentes zonas y probar respuesta rápida.
- [ ] Overlay: arrastrar en zona superior, central e inferior; anotar si Ajustes se mueve.
- [ ] Super Hex: comprobar que X cierra desde título y partida.
- [ ] Cubo: revisar respuesta táctil y rendimiento.
- [ ] Anotar cierres inesperados, toques equivocados y latencia percibida.
