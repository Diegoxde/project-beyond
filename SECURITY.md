# Seguridad

No publiques exploits, firmware propietario, claves, dumps completos ni identificadores personales del dispositivo en issues públicos.

Para problemas que puedan dejar la pulsera inutilizable, detén las pruebas y documenta primero el estado del firmware y la posibilidad de recuperación. Este proyecto no garantiza que las modificaciones sean seguras para instalar.

Project Beyond es experimental y no está afiliado a Samsung.
