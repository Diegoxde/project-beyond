# Versiones

No se publican binarios de firmware en este repositorio por ahora.

La versión más reciente mencionada en las notas del autor es `fit3-apps-toque-v24.bin`. Está validada por herramientas y arneses de PC, pero no confirmada en el reloj. No debe tratarse como una release estable.

Cuando se publique una versión futura, adjuntar código fuente permitido, checksum, pasos de recuperación, pruebas reproducibles y limitaciones conocidas. No subir firmware propietario ni imágenes completas de stock.
